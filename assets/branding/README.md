# Cargo plugin artwork

The Cargo icon and banner were generated with the built-in image_gen tool. The current banner uses the C-shaped transfer arrow, a cloud, storage drives, and a backup loop in the plugin's navy and blue palette.

- `icon-128x128.png` and `icon-256x256.png`
- `banner-772x250.png` and `banner-1544x500.png`

Source images in this directory:

- `cargo-icon-v2-original.png` — current full-size icon

Earlier concepts and the InsightX Offload sources were removed; they are in git history.

## Icon prompt

Use case: logo-brand. Create a sophisticated square WordPress plugin icon for Cargo, a WordPress media, storage, and backup transfer tool. Design an original abstract uppercase C monogram as one continuous heavy rounded geometric ribbon, with the open end subtly forming a forward-moving arrow. It should feel like a data route or transfer loop, not a parcel, cloud, truck, or generic upload icon. Premium contemporary software identity, flat vector-like shapes with carefully balanced negative space, sharp optical alignment, minimal subtle depth only if useful. Electric cobalt blue #2575f5 with a small aqua accent #41d5df on a solid very dark ink navy #0b1222 background. Strong silhouette, generous margins, extremely legible at 128 pixels. No lettering other than the abstract C-shaped mark, no words, no tiny icons, no gradients that obscure form, no glow, no mockup, no border, no watermark. Centered 1:1 square.

## Banner prompt

Use case: ads-marketing. Create a finished ultra-wide 3.088:1 WordPress plugin banner for Cargo, a plugin for cloud storage and website backup. Use the current icon only as a reference for the navy, cobalt blue, and aqua palette and C-arrow brand mark. Compose a polished, clear software product banner. Left half: exact title "Cargo" in a clean upright modern sans-serif typeface, medium-to-bold weight, normal proportions, not italic, condensed, futuristic or distorted. Under title, exact subtitle "Cloud Storage & Backup" in a smaller simple sans-serif. Right half: one cohesive crisp illustration of a white and blue cloud above a short stack of blue storage drives, connected by a smooth aqua backup loop with a visible circular arrow. The three ideas (cloud, storage, backup) must be visually obvious at thumbnail size. Use simple elegant dimensional vector-like shapes, consistent perspective, restrained soft lighting, no random floating media tiles. Full-bleed deep navy #0b1222 background, refined cobalt #2575f5 and aqua #41d5df accents. Balanced whitespace, high contrast, no text overlap. Do not use a box or parcel, extra text, provider logos, watermark, or border. Ensure exact spelling and natural letter shapes.
